АМИНО — развёртывание на VPS

1. Установите Node.js 22 или новее.
2. Распакуйте проект, например в /opt/amino.
3. Из этой папки запустите: node server.mjs
   Сайт: http://127.0.0.1:4174/
   Установка npm-пакетов и сборка не нужны.

ПОСТОЯННЫЙ ЗАПУСК
Создайте пользователя amino, дайте ему чтение проекта. Пример systemd:

[Unit]
Description=Amino quiz
After=network.target

[Service]
Type=simple
User=amino
WorkingDirectory=/opt/amino
Environment=HOST=127.0.0.1
Environment=PORT=4174
Environment=DATA_DIR=/var/lib/amino
Environment=PUBLIC_ORIGIN=https://YOUR_DOMAIN
ExecStart=/usr/bin/node /opt/amino/server.mjs
Restart=on-failure
StateDirectory=amino
UMask=0077
NoNewPrivileges=true

[Install]
WantedBy=multi-user.target

Проверьте путь к node: command -v node. Замените YOUR_DOMAIN реальным доменом.
Сохраните сервис в /etc/systemd/system/amino.service и выполните:
systemctl daemon-reload
systemctl enable --now amino

HTTPS
Поставьте Nginx или другой обратный прокси с HTTPS. В HTTPS-конфигурации домена:

location / {
    proxy_pass http://127.0.0.1:4174;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
    client_max_body_size 8k;
}

Проксируйте весь сайт, включая /api/, в Node.js. Не публикуйте папку проекта
целиком как каталог файлов: в ней серверный код и приватное хранилище.

ХРАНЕНИЕ
DATA_DIR/leaderboard.json создаётся автоматически. Без DATA_DIR файл находится
в private-data/ рядом с server.mjs. По HTTP сервер раздаёт только разрешённые
публичные файлы. Хранилище и серверный код по HTTP недоступны.

Один процесс Node.js последовательно обрабатывает запись, сохраняет временный
файл и атомарно заменяет основной. Не запускайте несколько процессов или
кластеров с общим JSON-файлом. Для небольшой аудитории отдельная база не нужна.
Google Drive и другие облачные сервисы не используются.

При обновлениях сохраняйте DATA_DIR; для контейнера используйте постоянный том.
Делайте резервные копии leaderboard.json вне публичной папки. Перезапуск
сервера не сбрасывает результаты.

УЧАСТНИКИ
Без паролей. Браузер сохраняет случайный секрет, сервер — его хеш. Очистка
браузера лишает доступа к профилю, но опубликованные результаты остаются.
Одинаковые имена не объединяются. Новое имя при пересдаче меняет имя в таблице;
история сохраняет имя на момент начала каждой попытки.

Сервер проверяет ответы и не начисляет баллы повторно при повторной отправке.
Это дружеский рейтинг: просмотр справочника и создание новых участников
не блокируются. В сумме учитываются лучшие завершённые попытки каждой темы.

СРОК ПОПЫТКИ
2 часа с момента начала. Закрытие вкладки не удаляет попытку; продолжение
доступно через «Прогресс». Истёкший срок сервер отмечает при следующем запросе.

ВЕРСИЯ ПРАВИЛ
2026-10-v7. Во всех семи темах по 30 вопросов: 15 прямых и 15 обратных.
Каждый экзамен охватывает все 20 стандартных аминокислот. Максимум рейтинга 210.
Перевод английских названий удалён; код не показан в вопросе,
когда его нужно выбрать в ответах. Все попытки v1 и v2 остаются в истории
и не входят в новый рейтинг; незавершённые старые попытки закрываются
при следующем запросе. Данные хранилища сохраняются при обновлении.
Третья ошибка завершает экзамен: статус «Не сдан», набранные баллы сохраняются.
Попытки v3–v6 совместимы с v7 и учитываются в рейтинге; текущие попытки можно продолжить.
Тема «Генетический код» добавляет до 30 баллов. Вопросы используют
кодоны мРНК стандартного генетического кода; Sec/Pyl исключены из этой темы.
Тема «История и этимология» добавляет ещё до 30 баллов; источники доступны после ответа.
Обнулённые v4 результаты восстанавливаются из сохранённых правильных ответов
при чтении; исходный JSON не переписывается ради этой корректировки.
Незавершённые попытки не входят в рейтинг. Звезда отмечает наличие сданной темы.
При изменении состава или правил обновите VERSION и isCurrentAttempt
в exam-core.js, чтобы несовместимые результаты не попадали в один рейтинг.
