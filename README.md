# Амино

Квиз для изучения аминокислот: названия, буквенные коды, классификация,
свойства, молекулярные формулы и химические структуры. Интерфейс рассчитан
в первую очередь на телефон.

**[Открыть сайт → amino.aarapov.xyz](https://amino.aarapov.xyz/)**

## Что есть

- Тренировки по 10 вопросов и повторение ошибок.
- Справочник с 20 стандартными аминокислотами и расширенным набором с Sec/Pyl.
- Прямые и обратные вопросы во всех пяти темах.
- Экзамены, история попыток, общий рейтинг и ссылки на результаты.
- Анимации и конфетти после сданного экзамена; поддержка уменьшения движения.

## Правила экзаменов

Темы: **названия и коды**, **классификация**, **формулы**, **структуры**, **свойства**.

Каждый экзамен содержит 30 вопросов по всем 20 стандартным аминокислотам:
15 прямых и 15 обратных. За правильный ответ — 1 балл.

Две ошибки допустимы. Третья ошибка завершает экзамен со статусом «Не сдан»
и результатом **0 баллов**. Незавершённая попытка также получает 0.
Во время экзамена отображается промежуточный счёт.

До начала участник указывает публичное имя. Попытка попадает в историю
независимо от результата. В рейтинге складываются лучшие сданные результаты
пяти тем: максимум **150 баллов**. Несданная пересдача не стирает лучший результат.

## Локальный запуск

Нужен **Node.js 22 или новее**. Сборки и установки зависимостей нет.

```sh
git clone git@github.com:EraCat/amino.git
cd amino
npm start
```

Откройте [localhost:4174](http://127.0.0.1:4174/).
Также можно запустить сервер командой `node server.mjs`.

Для тренировок и справочника достаточно статического хостинга или открытия
`index.html`. Экзамены и общий рейтинг требуют работающего Node.js-сервера.

## Хранение и развёртывание

Сервер использует стандартные модули Node.js и один приватный JSON-файл.
Отдельная база данных и облачное хранилище не нужны. Сервер проверяет ответы,
обрабатывает записи последовательно и сохраняет файл атомарно.

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `HOST` | `127.0.0.1` | Адрес прослушивания |
| `PORT` | `4174` | Порт приложения |
| `DATA_DIR` | `private-data/` рядом с сервером | Приватная папка результатов |
| `PUBLIC_ORIGIN` | Не задан | Публичный адрес сайта для проверки запросов |

На сервере используйте постоянную папку для `DATA_DIR`, резервные копии
и обратный прокси с HTTPS. Проксируйте весь сайт, включая `/api/`, в Node.js.
Запускайте один экземпляр приложения с данным JSON-файлом.
Пошаговый пример запуска через systemd — в [DEPLOY.txt](DEPLOY.txt).

Папка результатов, `.env` и файлы IDE исключены из Git. Не храните результаты
пользователей или секреты в публичном репозитории.

Участник определяется секретом в браузере; сервер хранит его хеш.
После очистки хранилища браузера опубликованные результаты остаются,
но доступ к прежнему профилю теряется. Это учебный рейтинг: доступ
к справочнику и исходному коду во время экзамена не блокируется.

## Данные

Классификации пересекаются. В квизе используется выбранная учебная схема;
особенности гистидина, цистеина и тирозина пояснены в справочнике.
В обратных вопросах исключены варианты, которые также удовлетворяют условию.
Например, лейцин и изолейцин имеют одинаковую молекулярную формулу.

Формулы относятся к свободным молекулам, а SVG — к нейтральным L-формам
с учётом стереохимии. Глицин ахирален. Изображения построены RDKit.

Источники: [IUPAC — коды](https://iupac.qmul.ac.uk/AminoAcid/A2021.html),
[NCBI — незаменимые аминокислоты](https://www.ncbi.nlm.nih.gov/books/NBK557845/),
[PubChem](https://pubchem.ncbi.nlm.nih.gov/) и
[Википедия — классификация](https://ru.wikipedia.org/wiki/Аминокислоты#Классификация).
Полный список и пояснения доступны в справке сайта и [README.txt](README.txt).
